Shaz's School of Motoring

A complete business website build for a DVSA-approved female driving instructor in Wolverhampton — from brand direction through to a fully optimized, production-ready site.

Overview

The Brief

A complete website build for a DVSA-approved female driving instructor based in Wolverhampton, UK. The brief evolved through close, iterative collaboration with the client — from early brand and colour exploration through to a polished, production-ready site now live at shazsschoolofmotoring.co.uk.

Features

Key Features

  • Custom hero design with a script-accent headline, dynamic background imagery, and animated scroll-reveal sections
  • WhatsApp-first booking flow with pre-filled, context-specific message templates for each service (standard lessons, ADI training, intensive courses)
  • Real testimonial showcase with an expandable "read more" interaction for longer reviews
  • A "pass wall" photo gallery of real student certificates, with responsive cropping that degrades gracefully across browser engines
  • Full structured data (Schema.org) markup and Open Graph tags for search visibility and social share previews
  • WCAG-conscious accessibility work — contrast ratios checked and corrected against real hex values, not eyeballed

Engineering

Technical Highlights

  • Diagnosed and resolved a critical position: sticky bug caused by a conflicting overflow rule — a subtle CSS interaction that had broken the sticky header
  • Took the page from a single 3.16MB self-contained HTML file to a properly structured, cacheable multi-file deployment (~63KB HTML + separate image assets), lifting mobile PageSpeed Performance from 55 to 92
  • Implemented modern image delivery: WebP formats with automatic JPEG/PNG fallback via <picture> elements, explicit width/height attributes to eliminate layout shift, and async font loading to remove render-blocking requests
  • Built defensive, dual-layer CSS (a percentage-padding fallback layered under the modern aspect-ratio property) so critical layout doesn't depend on a single browser feature being supported everywhere it's viewed
